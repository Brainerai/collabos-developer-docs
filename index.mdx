## Two API surfaces

CollabOS separates normal API usage from developer settings.

| Surface | Prefix | Authentication | Use it for |
| --- | --- | --- | --- |
| Data API | `/api/v1/...` | Personal or workspace API key | Raffles, entries, wins, winners, projects |
| Developer management | `/api/developer/...` | CollabOS dashboard/session JWT | Create and revoke keys, configure webhooks |
