## Two API surfaces

CollabOS intentionally separates normal API usage from developer settings.

| Surface | Prefix | Authentication | Use it for |
| --- | --- | --- | --- |
| Data API | `/api/v1/...` | Personal or workspace API key | Raffles, entries, wins, winners, projects |
| Developer management | `/api/developer/...` | CollabOS dashboard/session JWT | Create and revoke keys, configure webhooks |

<Note>
The exported OpenAPI contract does not define a production server URL. In examples below, replace `https://YOUR_API_BASE_URL` with the API origin for your CollabOS deployment.
</Note>
