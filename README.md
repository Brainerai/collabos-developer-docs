# CollabOS Developer Docs

Official developer documentation for the CollabOS API.

This repository contains the guides, API reference, authentication documentation, webhook documentation, and integration examples available to developers building with CollabOS.

## Documentation

The docs cover:

- Getting started with the CollabOS API
- Authentication and API keys
- Personal and workspace API access
- API scopes and permissions
- Raffles, entries, wins, and projects
- Pagination and rate limits
- Error handling
- Webhooks and event delivery
- Webhook signature verification
- Full API reference
